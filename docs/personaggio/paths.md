# Character Paths

Ottieni una progressione di Character Path ai Livelli 2, 4, 6 e 8. Ogni volta che ottieni una progressione di Character Path, puoi scegliere il Martial Path o lo Spellcaster Path. Ottieni determinati benefici in base al Path scelto.

## Martial Path

- **Combat Training:** Weapons.
- **Maneuvers:** impari 1 Maneuver.
- **Stamina Points:** ottieni 1 Stamina Point massimo.

### Class senza Stamina Regen

Una Class che inizia senza una Stamina Regen ottiene la Spellcaster Stamina Regen indicata di seguito la prima volta che sceglie il Martial Path.

**Spellcaster Stamina Regen:** una volta per Round, recuperi fino a metà dei tuoi SP massimi quando usi uno Spell Enhancement.

## Spellcaster Path

- **Combat Training:** Spell Focuses.
- **Spells Known:** impari 1 Spell.
- **Mana Points:** ottieni 3 Mana Points massimi.

### Class senza Spell List

Una Class che inizia senza una Spell List ottiene una Spell List a sua scelta di qualsiasi Class la prima volta che sceglie lo Spellcaster Path.

## Paragon Subclass

Al Livello 3, invece di scegliere una Subclass della tua Class, puoi prendere la Paragon Subclass.

### Novice Paragon

**Subclass Feature di Livello 3**

Ottieni un Class Talent a tua scelta della tua Class.

### Jack of one Trade

**Flavor Feature**

Ottieni 1 Trade Point.

### Expert Paragon

**Subclass Feature di Livello 7**

Ottieni un Class Talent a tua scelta della tua Class.

### Master Paragon

**Subclass Feature di Livello 10**

Ottieni un Class Talent a tua scelta della tua Class.
