# DC20 — Regole

Questo sito raccoglie le regole di gioco di DC20 in forma di manuale di consultazione. Il testo è in italiano; i termini di gioco restano in inglese.

## Fonti

| Fonte | Versione | Contenuto |
|---|---|---|
| DC20 Core Rules | Beta 0.10.5 | Regole base, combattimento, Maneuver, Spell, regole generali, creazione del personaggio, Ancestry, Class |
| DC20 Magazine 01 — Psion + Psyborn | Beta 0.8 | Class Psion, Ancestry Psyborn |
| DC20 Magazine 23 — The Summoner | Beta 0.10.5 | Class Summoner (Livelli 1–5) |
| DC20 Magic Pack | Beta 0.10 | Artificer, Magic Items, Magic Properties |
| DC20 Player Options Pack | — | Shadow Options, Expanded Ancestry Options |

I contenuti provenienti da versioni precedenti alla 0.10.5 sono segnalati in testa alla pagina.

## Convenzioni

- Ogni termine di gioco (Attribute, Check, Save, Condition, Spell, Maneuver, ecc.) è scritto in inglese con l'iniziale maiuscola, come nel manuale originale.
- I valori nelle righe di statistiche (Cost, Range, Duration, Area) sono riportati in inglese.
- Gli esiti dei tiri sono indicati con le etichette originali in grassetto: **Hit:**, **Miss:**, **Success:**, **Failure:**, **Save Failure:**, ecc.
- Le note di regola sono riportate in riquadri **Nota**. Gli esempi, quando presenti, sono in riquadri richiudibili.
- Le distanze sono espresse in Spaces (vedi [Environment](regole_generali/ambiente.md)).

| Sigla | Termine | Significato |
|---|---|---|
| AP | Action Point | Risorsa spesa per compiere Action |

| HP | Health Points | Punti ferita |
| PD | Precision Defense | Difesa contro attacchi di precisione |
| AD | Area Defense | Difesa contro attacchi ad area |
| DC | Difficulty Class | Classe di difficoltà |
| CM | Combat Mastery | Bonus di padronanza in combattimento |
| ADV | Advantage | Vantaggio |
| DisADV | Disadvantage | Svantaggio |
