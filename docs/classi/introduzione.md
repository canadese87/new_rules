# Introduzione alle Class

## DC20 Class List

Ogni personaggio appartiene a una Class, che ne definisce il ruolo, i punti di forza e la progressione. Le Class si dividono in due categorie principali: Martial e Spellcaster.

- Le **Martial Class** usano le capacità fisiche, le tattiche di combattimento e la Stamina.
- Le **Spellcaster Class** usano il potere magico delle Source Arcane, Divine o Primal.

Lo Spellblade combina disciplina marziale e lancio di Spell: è sia una Martial Class sia una Spellcaster Class.
