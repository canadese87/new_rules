# Game Master Guide

## Variable Attribute Skill Checks

Ogni Skill ha un Base Attribute, che è l'Attribute predefinito da aggiungere alla Skill a meno che il GM non richieda altro. Nella maggior parte dei casi si usa il Base Attribute della Skill (vedi [Skills](../regole_base/skills.md)).

??? example "Esempio"
    Un Athletics Check si basa di norma sulla Might; un Influence Check si basa di norma sul Charisma.

### Variable Attribute Rule

L'Attribute da usare per un determinato Skill Check dipende da come viene usata la Skill. Questa regola permette di creare qualsiasi combinazione di Skill e Attribute.

Per effettuare un Variable Skill Check si determinano 2 elementi:

- **Determine the Skill:** quale Skill il PC sta usando, in base a ciò che cerca di ottenere.
- **Determine the Attribute:** quale Attribute (Might, Agility, Intelligence o Charisma) il PC usa per svolgere il compito, cioè in che modo usa la Skill.

Il formato per indicare questi Check è "Skill (Attribute) Check": la Skill è la prima parola e l'Attribute usato è tra parentesi.

!!! note "Nota"
    - I giocatori possono proporre Attribute alternativi per i Check, ma il GM decide sempre quale Check il giocatore effettua.
    - Il GM dovrebbe scegliere un Variable Check adatto al PC. Se il Variable Check è peggiore per il PC, questi può sempre scegliere di usare lo Skill Check predefinito.

??? example "Esempi di Variable Check"
    - **Animal (Might) Check:** lottare con un cinghiale selvatico. Afferrare rapidamente un animale: Animal (Agility) Check.
    - **Trickery (Charisma) Check:** imitare la voce o l'accento di un altro NPC per farsi passare per lui. Ideare un piano astuto per infiltrarsi in un luogo: Trickery (Intelligence) Check.
    - **Medicine (Agility) Check:** rimuovere con attenzione schegge di metallo da un alleato. Praticare un massaggio cardiaco o rimettere a posto una spalla lussata: Medicine (Might) Check.
    - **Intimidation:** spezzare qualcosa a metà (Might); lanciare un pugnale che sfiora la testa di qualcuno (Agility); manipolare una creatura con minacce sociali, estorsione o ricatto (Charisma); minacciare usando informazioni chiave o conoscenze sul bersaglio, ad esempio elencando fatti spaventosi su una bestia (Intelligence).
    - **Insight (Intelligence) Check:** capire qualcosa basandosi su esperienze passate (intuito del PC).
